# ReactOrders
## Интерфейс - React 19
## Сервер - Next
## Корзина (store) - Redux
## БД SQLite - Prisma 7
## Авторизация - next-auth

## Сделать руками в терминале для новой БД (удалить старую orders.db)

### создание клиента Prisma
npx prisma generate

### создание БД
npx prisma db push

### заполнение случайными данными (миграция)
npx prisma db seed

### В системе заведены пользователи
- admin@ya.ru (все права)
- manager@ya.ru (+ редактирование клиентов)
- sales@ya.ru (+ редактирование товаров)
- у Гостя никаких прав нет
